# CrazyGames: Relict Swarm (Basic Launch)

## Сборка

Игру можно собрать автоматически без платных инструментов:

- `npm test` создаёт `dist/crazygames/index.html`, `telemetry-client.js` и `telemetry-config.js`.
- Push в `develop` запускает GitHub Actions **Build and verify modular game**, где в артефактах появляется **RelictSwarm-CrazyGames-test**, содержащий ZIP `RelictSwarm-CrazyGames-test.zip`.
- Для портала загружается **внутренний ZIP**, в корне которого лежит `index.html`. Не загружайте ZIP артефакта целиком: он содержит другой ZIP.
- В отдельном CrazyGames-издании в `<head>` подключён `https://sdk.crazygames.com/crazygames-sdk-v3.js`, далее SDK инициализируется асинхронно `CrazyGames.SDK.init()`.
- После инициализации вызываются `game.loadingStart()` и, когда меню готово, `game.loadingStop()`. При реальном входе в игровой забег вызывается `game.gameplayStart()`, при паузе, модальных экранах и завершении `game.gameplayStop()`.
- Смена вкладок не порождает лишних gameplay-событий, как рекомендует CrazyGames: фокус отслеживает площадка сама.
- В режиме `SDK.environment='disabled'` или при недоступном SDK игра не блокируется, но события SDK не отправляются.
- Реклама **не вызывается**, потому что Basic Launch не допускает рекламной монетизации.

GitHub Pages продолжает использовать `dist/index.html` без загрузки CrazyGames или Yandex SDK. Для Яндекса создаётся отдельная сборка `dist/yandex/`.

## Инструкция по загрузке

1. Открыть https://developer.crazygames.com/ и зарегистрировать аккаунт разработчика.
2. **Account → Billing**: указать реальные данные разработчика и проверить, какие способы выплат Tipalti доступны для вашей страны и банка. Не использовать ложные данные или чужую страну регистрации. Если метод выплат ещё недоступен, CrazyGames позволяет временно выбрать `Hold Payments`. Минимальный порог выплат: €100.
3. Создать игру через **Submit a game** и скачать `RelictSwarm-CrazyGames-test.zip` из последнего успешного Actions-запуска.
4. Загрузить ZIP, выбрать HTML5 и параметры десктоп/мобильной игры, горизонтальную ориентацию; открыть предпросмотр и QA.
5. В Preview проверить в частности загрузку меню, начало игры, выбор улучшений, паузу, победу и поражение, звук и сохраняемую постоянную прокачку. Проверить Chrome и мобильный браузер, в том числе iframe 907×510 и устройства с DPR 1.
6. Прежде чем отправлять на модерацию, закрыть блокеры ниже.

## Блокеры до публикации

- **Английский язык:** сейчас UI русскоязычный. Требуется перевод интерфейса и описание на английском; CrazyGames указывает отсутствие английского как возможную причину отказа.
- **Обложки:** три отдельных изображения одного визуального стиля: landscape **1920×1080**, portrait **800×1200**, square **800×800**. Никаких чужих логотипов, кнопок «Play Now» или рамок.
- **Видео:** CrazyGames просит горизонтальное и вертикальное превью, 15–20 сек, до 50 МБ, без звука и чёрных полос. Нужны реальные кадры игры.
- **Метаданные:** английское название `Relict Swarm`, описание, жанр, инструкция и скриншоты.
- **Тест SDK в Developer Preview:** unit-тесты и проверка сборки не заменяют реального тестирования на сайте.
- **Права на звук:** проверить лицензии всех используемых аудиозаписей.
- **Конфиденциальность:** игра использует добровольную анонимную телеметрию Cloudflare. Проверить её разрешённость и при необходимости опубликовать политику конфиденциальности.
- **Биллинг:** заранее проверить разрешённый способ выплаты в Беларуси или своей фактической стране регистрации.

## Основные ограничения

- Basic Launch длится примерно 7–21 день; видео- и rewarded-реклама **выключены** и дохода от рекламы нет.
- Только после перехода на Full Launch возможен доход с рекламы, и SDK становится обязательным.
- Общий размер ≤ 250 МБ, до 1500 файлов; начальная загрузка ≤ 50 МБ, для мобильной главной страницы ≤ 20 МБ.

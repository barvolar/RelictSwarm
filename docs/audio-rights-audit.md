# Relict Swarm audio rights audit

Last updated: 2026-11-03

## Release status: audio sample remediation implemented in `release/licensed-procedural-audio`

The previous build bundled approximately 3.5 MB of audio recordings with undocumented origin. These recordings must **not** be treated as CC0, royalty-free, or commercially cleared based on their filenames. A potential Pixabay source for the mine sample does not establish the provenance of the actual embedded audio.

### Changes in the procedural-audio release candidate

- Replaced `src/modules/30-audio/embedded-bank.js` with pure JavaScript synthesis presets. It contains **no third-party sound files, base64 samples, or music recordings**.
- Changed `src/modules/30-audio/engine/playback.js` to create sound effects and two stereo background themes locally via the Web Audio API.
- The weapon/UI effects, continuous loops, two themed tracks, master compressor, per-category sliders and pause/mute behavior remain available.
- Added `tests/audio-rights.test.mjs` to block accidental reintroduction of encoded audio samples and verify the procedural sound registry.
- The old audio remains in prior Git commits (as is normal with Git history). It is not part of the new source/runtime bundle after the staged HTML has been rebuilt.
- Procedural replacement changes the sound design. This is a technical rights-remediation candidate, **not** an assertion that the sounds have been artistically approved.

### Attribution / provenance inventory

| Asset group | Current source | Attribution / license status |
|---|---|---|
| One-shot sound effects (weapon, hit, explosion, UI) | Functions in `src/modules/30-audio/embedded-bank.js` | Generated by original project code; no downloaded audio recording |
| Continuous effects (flame, saw, rocket, plasma, cryo, gravity, boomer, burn) | Same code, repeating Web Audio buffers | Generated by original project code; no downloaded audio recording |
| `menu_theme` | `relictMusicBuffer(ctx,false)` | Original procedural arrangement, no imported recording |
| `combat_theme` | `relictMusicBuffer(ctx,true)` | Original procedural arrangement, no imported recording |

No external audio artist attribution is required for these **generated signals as such**, because no external recording or composition is used by these modules. This does not replace due diligence concerning who owns or may license the repository's original code.

### Commercial publication checklist

1. Run `npm test`, inspect the final `dist/crazygames/index.html`, and verify no old audio bank survives in the shipped package.
2. Test the revised sounds, music, volume sliders, focus changes and mobile browser playback on real devices. Browser-unit tests are not an acoustic evaluation.
3. Check code ownership and all non-audio materials independently (including any externally contributed code, cover graphics, fonts, and CrazyGames SDK terms).
4. Keep a clear code ownership and distribution policy. **No `LICENSE` file** means no open-source permission is granted by default; it is not evidence of third-party infringement or of clean title.
5. Re-check documentation, external platform terms, telemetry/privacy disclosures, and the required release assets before submitting the game.

**Result:** the unverified embedded audio recording blocker is eliminated in the procedural build once the new compiled HTML ships. A complete legal release clearance is **not** claimed.

### Historical finding (replaced audio)

The 2026-11-03 baseline audit found no per-file author, download URL, license, version, or change notice for the former 55 encoded records. In particular, the mine placement recording was previously identified by a filename resembling `freesound_community-spawn-sound-43782`, but this alone does not confirm rights to the exact bytes used. If any former recording is restored, the creator/source/license must be documented individually, and CC BY-NC samples must not ship commercially without separate permission.

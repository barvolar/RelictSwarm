# Разработка «Реликтового роя»

Рабочая ветка: **develop**. Публичный GitHub Pages продолжает обслуживаться из **main**.

## Сборка

Требуется Node.js 20+. Никаких npm-зависимостей, платных библиотек или серверов.

```bash
npm run build
npm test
npm run preview
```

Готовая игра находится в `dist/`, предпросмотр: http://127.0.0.1:4173/. Для публикации использовать **содержимое dist**, а не папку src.

## Системы

- `src/index.template.html`: разметка экрана
- `src/styles/game.css`: стили, мобильная адаптация
- `src/modules/10-data/`: оружие, враги, боссы, синтезы и волны
- `src/modules/20-core/`: ввод и состояние
- `src/modules/30-audio/`: звуковая библиотека и воспроизведение
- `src/modules/40-game/`: боевые механики, прокачка, спавн и игровой цикл
- `src/modules/50-ui/`: меню, настройки
- `src/modules/60-analytics/`: FPS и баланс
- `src/modules/70-render/`: графика
- `src/modules/90-bootstrap/`: запуск
- `telemetry-client.js`, `telemetry-config.js`: опциональная отправка статистики

Очередность соединения исходников задаётся `src/module-order.json`.

## Важное о миграции

Это первый, безопасный этап рефакторинга: **отдельные файлы исходников с общей областью видимости**, а не независимые ES-модули. Код прежней v0.10.15 склеивается в точности в исходном порядке, чтобы не менять инициализацию, баланс, сохранения, анимации и звук.

`npm test` подтверждает, что HTML побайтово совпадает с исходной v0.10.15. После будущих намеренных правок код изменится и этот исторический тест нужно заменить полноценными регрессионными тестами. Независимые ES-модули и Vite добавляются на следующих этапах после выделения интерфейсов и тестирования.

**Не изменять main без тестов и Pull Request.** Не записывать секреты Cloudflare в публичный JavaScript.

# Реликтовый рой v0.10.15 — онлайн-тест

Готовый статический сайт для GitHub Pages. Код игры и баланс взяты из v0.10.14. Добавлена **отключённая по умолчанию** автоматическая статистика; для её работы требуется отдельный сервер Cloudflare Workers + D1 и согласие игрока.

## Как опубликовать без установки программ

1. Создайте **публичный** репозиторий `RelictSwarm` в https://github.com/new (на бесплатном GitHub Pages нужен публичный репозиторий).
2. Распакуйте этот архив. Откройте репозиторий, нажмите **Add file → Upload files** и загрузите **файлы из папки**, а не ZIP целиком: `index.html`, `telemetry-config.js`, `telemetry-client.js`, `.nojekyll`, `README.md`. Файл `.nojekyll` можно добавить позже, если веб-загрузка скрывает скрытые файлы.
3. Сделайте **Commit changes** в ветку `main`.
4. Откройте **Settings → Pages → Build and deployment → Source: Deploy from a branch**, выберите `main` и `/(root)`, нажмите **Save**.
5. После публикации адрес будет: `https://barvolar.github.io/RelictSwarm/`. На телефоне открывать **именно эту HTTPS-ссылку**, не локальный HTML.

**Важно:** публикация делает файлы игры общедоступными. Не загружайте сюда рабочие исходники, приватные ключи или личные файлы. Секретные пароли нельзя вставлять в `index.html` или `telemetry-config.js`.

## Аналитика

Пока в `telemetry-config.js` значение `endpoint` пустое, онлайн-отправка отключена. Локальные отчёты FPS и баланса продолжают работать.

После настройки отдельного сервера `RelictSwarm_v01015_analytics` впишите в `telemetry-config.js` публичный адрес приёмника, например `https://example.workers.dev/ingest`, и загрузите изменённый файл на GitHub.

Тогда при первом посещении игра спросит согласие на анонимную статистику. При согласии отправляются результаты забегов, изменения по боссам, число врагов, выбор оружия, FPS и время кадра. Каждые ~30 секунд отправляется агрегированный снимок; по завершении — подробный отчёт. При отсутствии сети данные временно хранятся на устройстве и отправляются позже. Нельзя собирать персональные данные, адреса, сообщения или ввод с клавиатуры.

Настройка согласия доступна в игровом разделе **Настройки**. При отказе отправка прекращается и локальная очередь очищается.

## Файлы

- `index.html`: готовая игра.
- `telemetry-client.js`: механизм передачи игровой статистики.
- `telemetry-config.js`: **публичный** адрес аналитического сервера (не содержит секретов).
- `.nojekyll`: отключает обработку Jekyll для статического сайта GitHub Pages.

## Что протестировано

Проверка синтаксиса JavaScript; загрузка меню через встроенный тестовый браузер; раздел настроек с выключенной аналитикой; SQL-структура для Cloudflare D1. Полноценное открытие адреса GitHub Pages и отправка на реальный Cloudflare Worker возможны только после публикации и настройки сервисов.

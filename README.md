# Реликтовый рой

**Реликтовый рой** — браузерный арена-рогалик на выживание с автоматическими атаками, прокачкой оружия и битвами с боссами. Игрок управляет боевым роботом, отражает волны противников, собирает улучшения и экспериментирует с комбинациями вооружения.

**[▶ Играть в браузере](https://barvolar.github.io/RelictSwarm/)**

Игра доступна по ссылке на ПК, Android и iPhone. Установка не требуется. Мобильные устройства поддерживаются, однако совместимость и производительность продолжают тестироваться.

## Особенности

- **Динамичные забеги:** волны врагов, элитные противники, особые события и боссы.
- **Автоматический бой:** оружие атакует самостоятельно, а игрок сосредоточен на перемещении, уклонении и выборе позиции.
- **Развитие вооружения:** до пяти видов оружия за забег; улучшения характеристик разной редкости.
- **Синтез оружия:** комбинации вооружения открывают новые боевые механики.
- **Разные стратегии:** можно развивать урон, скорострельность, радиус действия, количество атак и другие параметры.
- **Прогресс между забегами:** постоянные улучшения и косметические варианты робота.
- **Поддержка телефонов:** адаптированный интерфейс и сенсорное управление.

## Как играть

1. Запустите игру по ссылке выше и выберите **«Играть»**.
2. Перемещайтесь по арене, избегая столкновений и атак противников. Оружие стреляет автоматически.
3. Получайте уровни, выбирайте новые виды оружия и усиливайте уже имеющиеся.
4. Побеждайте боссов, ищите сочетания улучшений и старайтесь продержаться до конца забега.

**На телефоне** используется плавающий виртуальный джойстик. Для рывка предусмотрено управление вторым касанием. Интерфейс рассчитан на портретный экран.

## Статус разработки

**Текущая версия: v0.10.15 · Online Test**

Проект находится в активной разработке и открытом тестировании. Сейчас основное внимание уделяется:

- балансу количества врагов, сложности боссов и эффективности оружия;
- плавности работы на мобильных устройствах;
- удобству интерфейса и управления;
- поиску ошибок и улучшению игрового процесса.

Механики и параметры могут меняться между версиями.

## Статистика и конфиденциальность

В игре предусмотрены локальные диагностические отчёты о забегах, балансе и производительности. Их можно сохранить вручную для анализа.

Также подготовлена поддержка **добровольной анонимной онлайн-аналитики**. Она не отправляет данные, пока не подключён сервер аналитики и игрок не дал согласие. При подключении могут передаваться игровые события, результаты забегов, показатели FPS, сведения о характеристиках устройства и версии игры. Согласие настраивается в меню игры.

## Обратная связь

Сообщения об ошибках, проблемах с производительностью и предложения по балансу можно оставлять в разделе **[Issues](https://github.com/barvolar/RelictSwarm/issues)**. Особенно полезно указать устройство, браузер, версию игры и момент возникновения проблемы.

## Техническая информация

Проект работает на **HTML5 и JavaScript**. Публикация осуществляется через GitHub Pages.

| Файл | Назначение |
| --- | --- |
| `index.html` | Основная браузерная игра |
| `telemetry-client.js` | Клиентский модуль статистики |
| `telemetry-config.js` | Публичная конфигурация подключения аналитики |
| `.nojekyll` | Настройка публикации GitHub Pages |

Сервер аналитики не входит в этот репозиторий и не нужен для обычного запуска игры.
